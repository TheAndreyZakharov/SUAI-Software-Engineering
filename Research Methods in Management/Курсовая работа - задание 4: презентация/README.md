Цель работы:  
Освоение работы с нейросетевым сервисом «Gamma» для автоматизированного создания презентации и экспорта слайдов в формат PPTX на основе статьи, выполненной по заданию №3 КР МИВМ.  
Задание:  
​1.​Авторизоваться на сайте gamma.app.  

​2.​Создать новый документ, выбрать опцию «Сгенерировать».  

​3.​Ввести в текстовое поле текст статьи (работы) по заданию №3.  

​4.​Сформировать презентацию (набор из 8 слайдов по умолчанию), описывающую содержание статьи.  

​5.​Последовательно экспортировать каждый слайд в формат PPTX и сформировать из них отдельный документ, являющийся отчетом по заданию №4.
