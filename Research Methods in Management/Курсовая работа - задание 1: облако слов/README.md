Цель работы:   
Изучить и применить возможности низкокодовой текстовой аналитики в Voyant Tools на материале собственной бакалаврской работы. Для достижения цели будут построены и сопоставлены облака слов по каждой главе и по всему тексту в целом, чтобы выявить частотные термины и ключевые тематические акценты.  
 
Задание:   
1. Прочитать текст про инструмент Voyant Tools.  
2. Скачать инструмент Voyant Tools.  
3. Из Вашей бакалаврской работы для каждой главы и для работы в целом построить облако слов (должно получиться всего 4   рисунка Ваших облаков: отдельно по каждой главе и по работе в целом).
