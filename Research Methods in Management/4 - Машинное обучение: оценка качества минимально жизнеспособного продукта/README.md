Цель работы:   
Освоить применение методов машинного обучения к задачам многоклассовой классификации в MATLAB (приложение Classification Learner): подготовка синтетической обучающей выборки, настройка кросс-валидации, обучение и сравнение нескольких семейств моделей (деревья, LDA, k-NN, SVM и др.), оценка качества (Confusion Matrix, ROC/TPR-FPR, предсказания), экспорт лучшей модели и прогноз на новых данных. Реализовать аналогичную процедуру для задачи конкурентного окружения (5 признаков, 3 класса).  
Задание:   
       1.      Сформировать обучающую выборку из 45 наблюдений (по 15 на класс):  
• для MVP: X1…X5 → класс 1/2/3;  
• для конкурентного окружения: Audience, NewEntrants, Suppliers, Substitutes, Rivalry → «благоприятная/средняя/неблагоприятная».  
       2.      Загрузить таблицу в Classification Learner, указать Y как Response, предикторы — 5 признаков, включить 5-fold cross-validation.  
       3.      Обучить набор моделей (деревья, LDA, k-NN, SVM, логистическая регрессия, нейросети и др.), сравнить по Accuracy (Validation).  
       4.      Проанализировать Confusion Matrix, ROC-кривые, Scatter (Model predictions) и Parallel Coordinates.  
       5.      Выбрать модель-победитель, Export Compact Model, выполнить прогноз predictFcn(Xnew) для нового наблюдения.  
       6.      Повторить пункты 2–5 для задачи конкурентного окружения.
