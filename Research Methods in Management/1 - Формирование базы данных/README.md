Цель работы: 

Научиться создавать смоделированную базу примеров, которую можно использовать для решения различных задач.

Задание: 

Сформировать      базу примеров, состоящую из 20 строк (объектов) и 3 столбцов (признаков).  Каждый признак (столбец) подчиняется нормальному закону при следующих оценках среднего значения (СЗ) и среднеквадратичного отклонения (СКО):

          Х1: СЗ =10; СКО = 2;   
          Х2: СЗ =20; СКО = 3;   
          Х3: СЗ =70; СКО = 5.  
          
Самостоятельно сформировать базу примеров из области, представляющей практический интерес.   
Студенты с нечетным порядковым номером выполняют вариант 1, с четным - вариант 2.  
 
Вариант 4 - четный порядковый номер -> вариант 2  
 
Вариант 2   Компетенции персонала  
 
         В качестве входных параметров были взяты оценки компетенции, выставленные    руководителем, подчиненными, коллегами и, кроме того, была включена самооценка.   Таким образом, число входов равно четырем.  Диапазон шкалы оценок: от 1 до 10 баллов.       Выходной параметр - класс сотрудников.   Установим   для них   два значения: с   высокими (класс 1)    и низкими (класс 2) оценками и смоделируем базу примеров, используя метод Монте-Карло.  Объем моделирования определим в 40 сотрудников, по   20 человек   для каждого класса. В итоге, база примеров состоит из 40 строк и 5 столбцов (4 столбца - входные признаки, пятый - номер класса), т.е. каждый сотрудник описывается вектором-строкой из четырех компонентов.
